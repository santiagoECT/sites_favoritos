# 🌟 Sites Favoritos

Página web simples desenvolvida em **HTML5** para organizar e acessar rapidamente os sites e portais favoritos do dia a dia.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Página e dos elementos de navegação.
* **Git & GitHub**: Controle de versão e hospedagem do código-fonte.
* **Visual Studio Code**: Ambiente de desenvolvimento integrado (IDE).
